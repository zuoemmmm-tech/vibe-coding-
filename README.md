# 🧠 Decision Memory · 人生决策数据库

> **把每一次选择，变成你未来的判断资产。**

---

## 💡 为什么会有这个应用？

我们每天都在做选择——小到“今晚吃什么”，大到“换不换工作”、“要不要分手”。  
但大多数时候，我们靠直觉、问朋友、或者临时让 AI 给个建议，然后……就没有然后了。  

**Decision Memory 想解决的是**：

- ❌ 做决定时思路乱糟糟，缺少结构化思考；
- ❌ 做完就忘，从不复盘，好经验留不住，烂坑反复踩；
- ❌ 过去的重要经历（后悔的、庆幸的）被丢在记忆角落，没法在未来调用；
- ❌ 性格测试、年度总结做了一堆，却变成限制自己的标签，而不是成长的参考。

> **所以我们定了个核心原则：**  
> **过去是证据，测试是参考，未来目标才是方向。**

---

## ✨ 现在能做什么？（当前 MVP 功能）

目前版本是**本地可运行的原型**，已经能把“决策-记录-复盘”这个闭环跑通。具体来说：

### 1️⃣ 导入你的“起点资料”
粘贴你已有的东西，比如 MBTI、年度总结、简历、甚至和 AI 的聊天摘要。  
系统会提取“起点理解”，但**不会把你贴标签**——你可以随时校准它。

### 2️⃣ 校准你的起点档案
对系统提取的内容，你可以打上：
- ✅ 准确  
- 🟡 想保留  
- 🔄 想改变  
- ❓ 不确定  

这样就能避免“因为我是 INFP，所以我不适合做销售”这种死板判断。

### 3️⃣ 记录当前决策（决策卡片）
遇到重要选择时，直接录入，系统会帮你生成结构化卡片，包含：
- 问题一句话
- 背景
- 可选方案
- 关键判断标准
- 主要风险
- 下一步验证动作
- 未来目标校准
- 经验沉淀

### 4️⃣ 复盘过去经历
把你后悔的、庆幸的、转折点的经历放进去，它会变成**历史样本**，供未来参考，而不是日记本。

### 5️⃣ 浏览你的决策库
所有卡片都存本地，随时回看、删除、继续补充。

### 6️⃣ 决策助手
输入一个新问题，系统会从你已有的记录里“翻旧账”，帮你构建一个基于你个人历史的判断框架。

### 7️⃣ 复盘记录
每条决策都能补充最终结果、判断得失、以及下次遇到类似情况的行动规则。
